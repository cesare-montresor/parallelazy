## v0.2.7 (2026-11-27)

### Added
- Exported `ManagerOptions` from top-level `parallelazy` (`__all__`).
- Added `parallel: bool = True` support to `PluginManager.stop_all_plugins()` and `PluginManager.unload_all_plugins()`.
- Added PEP 561 inline typing support (`parallelazy/py.typed`), packaged in wheel/sdist data with the `Typing :: Typed` classifier.
- Added `@overload` signatures for `wait: Literal[True]` vs `Literal[False]` on `Plugin.env_set()` and `PluginWorker` RPC helpers (`plugin_load`, `plugin_start`, `plugin_stop`, `plugin_unload`, `env_set`, `env_unsubscribe`, `topic_list`).
- Added `[tool.ruff]`, `[tool.mypy]`, and `[tool.pyright]` configurations in `pyproject.toml`.

### Changed
- Converted `sanitize_for_ipc()` to copy-on-write for containers (`dict`, `OrderedDict`, `defaultdict`, `list`, `tuple`, `namedtuple`, `set`, `frozenset`) while preserving cycle detection.
- Batched NVML GPU queries in `PipelineMonitor` to once per sample instead of once per plugin, and switched pipe backlog inspection to `termios.FIONREAD`.
- Deduplicated `PluginWorker` RPC wait/error handling via `_await_rpc()`, moved `_deliver_to_subscribers()` to `plugin_transport.py`, and backed `CommandType.commands()` with a `frozenset` for O(1) lookup.
- Optimized `_TeeTextStream` line buffering and cached `(st_dev, st_ino)` in `_RecoveringFileHandler` to halve per-record stat syscalls.
- Removed obsolete `update.sh`.

### Fixed
- Closed `PluginCoreRPC._shutdown` pipe FDs on shutdown, closed/joined topic subscriptions and subscriber pipes on `PluginWorker.shutdown()`, and closed replaced `Subscriber` handles on re-subscribe.
- Enforced single-publisher topic ownership in `PluginManager._respond_topic_announce()` and serialized concurrent first-time `topic_announce()` calls.
- Hardened `env_subscribe()`: initial `env_get` timeouts/errors now unsubscribe and return `False`, while callback exceptions notify `on_error` and keep the subscription active.
- Removed duplicate traceback logging in `PluginCoreRPC._execute_command()` and redundant `sanitize_for_ipc()` in `PluginWorker._respond_call()`.
- Fixed `PipelineMonitor` idle CPU reporting (`0.0%` instead of `-`), pruned stale `_previous_topic_bytes` entries, called `nvmlShutdown()` on `stop()`, and honored updated `sample_interval` on repeated `enable_monitoring()` calls.
- Annotated remaining public API signatures and resolved all `mypy` and `pyright` type errors across `parallelazy/` (0 errors, 0 warnings), including explicit `| None` defaults, `Request.command` type alignment, `MessageUID.current() -> int`, `PluginWorker._respond_status() -> PluginStatus`, `PluginWorker._respond_env_update() -> bool`, `PluginManager._respond_env_set() -> bool`, and `PluginManager.work_dir` setter ordering.
