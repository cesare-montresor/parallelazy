## v0.1.1 (2026-11-18)

### Added
- Explicit `load` / `unload` / `start` / `stop` plugin lifecycle methods and `start_plugins()` with parallel loading support.
- Run-correlated logging module (`parallelazy/plugin_logging.py`) with support for updating `work_dir` and `log_dir` outside `PluginManager.__init__`.
- Status messages for the IPC protocol and unit test suites for plugin lifecycle, logging, and CUDA IPC.

### Changed
- Updated `Plugin.main()` to run once instead of looping implicitly, with stronger lifecycle synchronization and a more graceful stop sequence.
- Improved IPC handling across manager, worker, and transport layers.
