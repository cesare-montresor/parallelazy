## v0.2.0 (2026-11-23)

### Added
- Completed `Plugin` and `PluginManager` APIs and wired up `on_error()` with `PluginState.ERROR`.
- Added `IpcEventCuda.is_cleared()` for generation-aware CUDA IPC acknowledgment checks.
- Declared optional `monitoring` extras (`psutil`, `nvidia-ml-py`) in `pyproject.toml`.
- Added refreshed end-to-end examples (`example_quickstart`, `example_tensor_pipeline`, `example_live_config`, `example_dynamic_orchestrator`, `example_resilience_and_errors`, `example_cuda_zero_copy`) and expanded real-process and chaos/SIGKILL test suites.

### Changed
- Reused the topic listener selector and switched to single-pass tensor detection for lower pub/sub overhead.
- Synchronized documentation (`docs/`, `README.md`, `AGENTS.md`) and `.vscode/launch.json` with the 0.2.0 APIs and examples.

### Fixed
- Hardened RPC reliability for peer disconnects, `EOFError`, request timeouts, strict FIFO `ENV_UPDATE` delivery, and quieter shutdown-time rejection logging.
- Enforced strict pub/sub pipe ownership, resilient fan-out, and topic listing/unsubscription behavior.
- Hardened `sanitize_for_ipc()` for nested containers/cycles and improved CUDA IPC event pool handling.
- Fixed lifecycle locking, unload cleanup, `PluginManager` context manager teardown, `env_get()` `None` vs. unset semantics, descriptor default-option merging, `write_logs=False` directory creation, and monitoring hotkey shutdown.
