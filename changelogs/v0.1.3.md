## v0.1.3 (2026-11-19)

### Added
- `write_logs` option on `PluginManager` to disable log file and directory creation when not needed.
- Dedicated work-queue dispatcher for asynchronous environment updates.
- Additional unit tests covering environment callbacks, lifecycle transitions, and logging behavior.

### Changed
- Hardened thread safety in `PluginManager` and environment handling using `RLock` and improved plugin lifecycle management.
- Updated `env_subscribe()` so subscribers receive the current value upon registration.
- Updated minimum Python requirement to 3.11+ and made `debugpy` optional.

### Fixed
- Fixed topic subscription/unsubscription edge cases, RPC error handling, and resource cleanup during plugin unload.
