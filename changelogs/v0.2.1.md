## v0.2.1 (2026-11-23)

### Added
- Continuous atomic monitoring report file output via `PluginManager.enable_report_file()` / `disable_report_file()`, `PipelineMonitor.format_report()`, and `report_file` / `report_hotkey` parameters on `enable_monitoring()`.
- Windows console hotkey support (`msvcrt`) alongside POSIX TTY support in `PipelineMonitor`.
- Packaged AI Agent Skill (`parallelazy/SKILL.md`) with the `python -m parallelazy agent-guide` and `python -m parallelazy install-skill` CLI and top-level helpers (`get_agent_guide`, `get_agent_guide_path`, `install_skill`).

### Changed
- Overhauled `README.md` with architecture diagram, feature table, and CLI/monitoring guides, and updated `docs/api.md` for report file monitoring.
- Updated `pyproject.toml` to package `SKILL.md` and aligned license metadata with `LICENSE` (`GPL-2.0-only`).
