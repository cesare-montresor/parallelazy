## v0.0.4 (2026-10-21)

### Added
- Initial `parallelazy` release with spawn-isolated `Plugin` workers, `PluginManager`, topic-based pub/sub, shared `EnvironmentManager`, plugin-to-plugin RPC, and PyTorch/CUDA-aware IPC transport.
- Documentation suite under `docs/` (`index.md`, `getting-started.md`, `concepts.md`, `api.md`, `examples.md`, `troubleshooting.md`) and runnable examples under `examples/`.
- VS Code launch configurations (`.vscode/launch.json`) and GitHub Actions PyPI release workflow (`.github/workflows/publish.yml`).

### Fixed
- Fixed a race condition during `plugin_start`.
- Cleaned up imports across the example modules.
